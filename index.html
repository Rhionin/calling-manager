    Does this leave my computer?

    Names and callings stay in this browser. Church policy is clear that membership data should not be sent to third-party servers.

    What happens when I paste a report?

    The paste is read by a script in this page. There is no form upload and no request back to a server. After the board is built, the text box is cleared.

    Where is the board saved?

    Automatically in this browser (local storage and, when the browser allows it, IndexedDB). Export writes a JSON file only when you ask. A passphrase option encrypts that file in the browser before download. Nothing is sent anywhere to do that.

    How can I check?

    This page includes a Content-Security-Policy that sets connect-src 'none', so the browser refuses network connections from the page. You can also disconnect from the network after the page has loaded and keep working. Libraries and fonts are files in this copy, not CDN links.
