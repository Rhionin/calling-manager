# Calling Manager

Unmodified client capture of [callingmanager.com](https://callingmanager.com/), kept as a baseline so later changes stay reviewable.

The original tool was written by Justin Sirois (Tech Forum user jds580s) and published at callingmanager.com. The author has described the code as open source. This capture did not include a published license file. Attribution to the original author is retained.

This baseline is the wget capture of the live site's client code (`index.html` with inline scripts, stylesheets, and images). It is not the privacy-preserving local fork.
